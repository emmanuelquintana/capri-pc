# Capri para PC

Capri en tu escritorio: Windows 10 y 11, Mac (Intel y Apple Silicon) y Linux (Ubuntu 24.04 o más nuevo).

## Descargar

Entra a **[Releases › la más nueva](https://github.com/emmanuelquintana/capri-pc/releases/latest)** y baja el tuyo:

- **Windows**: el archivo `_x64-setup.exe`.
- **Mac**: el `.dmg`. Arrastra Capri a Aplicaciones; la primera vez, clic derecho › Abrir.
- **Linux**: el `.deb` o el `.AppImage`. Para el control de música, instala `playerctl`.

Una vez instalada, Capri se actualiza sola.
